# Lucas Belmiro dos Santos

Electronic and Telecommunications Engineering student at **UNESP**, São João da Boa Vista, Brazil.

I work on academic projects that connect electronics, biomedical optics and scientific computing. My interests include computer vision, explainable AI and research software.

## Research and projects

| Project | Focus |
| --- | --- |
| XAI in dermoscopy | Academic reproduction and adaptation of concept based skin lesion classification, using Python and PyTorch |
| Optical instrumentation | Laser current control and a PyQt interface for a spatially resolved diffuse reflectance system |
| Light transport in tissue | Monte Carlo simulation and computational modeling of optical propagation |

The XAI project includes models trained in Google Colab, source references, implementation history and documented limitations. It follows [Patrício et al. (CVPR Workshops, 2023)](https://openaccess.thecvf.com/content/CVPR2023W/SAIAD/html/Patricio_Coherent_Concept-Based_Explanations_in_Medical_Image_and_Its_Application_to_CVPRW_2023_paper.html). The Qt and Monte Carlo repositories will follow.

## Tools I use in academic work

Python, PyTorch, NumPy, pandas, PyQt, Raspberry Pi, SPI and LTspice.

My electronics studies also include control systems, RF and microwave engineering, antennas and wireless communications.
